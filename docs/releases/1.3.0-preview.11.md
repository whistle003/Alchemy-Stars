# Alchemy Stars 1.3.0-preview.11

Preview 11 makes model-part import safer by classifying CAST assets from their skeleton structure while keeping every recommendation reviewable and editable.

## Changes

- View hands, weapons and attachments are detected from bone topology rather than filename alone.
- A complete left/right arm rig remains View hands even when it contains the common helper `j_gun` and weapon attachment tags.
- Weapon roots, attachment tags and mechanism bones determine Weapon recommendations and automatically suggest `tag_weapon` parenting.
- Attachment-root models are identified separately, including small magazine-style rigs.
- File picker, list drop, path-field drop and typed/pasted path entry all use the same engine classifier. Interactive imports parse in the background.
- The inspector shows localized confidence, bone count and evidence. Manual type and parent overrides remain available and are never hidden.
- Classification evidence is not serialized, so opening and saving an existing `.aprj` does not silently change its model-part configuration.
- Self-contained topology fixtures and the real Hawk export smoke test protect the classification contract.

## Status

This remains a .NET 11 Preview / Avalonia Native AOT test release. WPF v1.1.9 on `main` remains the stable production line until .NET 11 GA.
