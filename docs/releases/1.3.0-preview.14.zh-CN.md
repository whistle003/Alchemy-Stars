# Alchemy Stars 1.3.0-preview.14 · Avalonia Native AOT

本次发布来自 `codex/avalonia-aot` 分支，汇总 preview.12–preview.14 的双持动画工作流更新。

**下载文件名按指定使用 `AlchemyStars-1.3.0-preview.11-win-x64.zip`，压缩包内程序的实际版本是 `1.3.0-preview.14`。文件名中的 preview.11 不代表程序回退。**

这是 Windows x64 预览版本，基于 .NET 11 Preview 7 和 Avalonia 12.1.2，使用自包含 Native AOT 发布，无需单独安装 .NET 运行时。原有稳定版不受此次预览发布影响。

## 双持动画工作区

- 新增左侧「双持动画」栏目，支持新建任务、按 `_l_` / `_r_` 文件名配对、选择左右动画来源、编辑挂点和预览合成结果。
- 当前实现挂点模式：一份手臂模型和一份单持武器模型，生成左右两份武器实例。
- 左右来源分别复用姿势、动画叠加层和 IK 处理管线，再逐帧求解左右挂点的局部动画。
- 输出统一骨架、正确重映射的蒙皮网格和一个合成动画；左右事件使用独立名称前缀。
- 双持任务通过持久 ID 引用源动画，配置随工程保存。修改来源、模型或配置后需重新生成预览。

## 独立导出武器模型

- 新增「导出武器模型」开关，默认开启，并按双持任务保存。
- 开启时额外输出 `动作名_model.cast`，包含手臂、左右武器的全部网格、蒙皮和统一骨架，不含动画。
- 配套模型不受动画输出格式和全局「仅动画 CAST」设置影响。SMD、SEAnim 动画也可以获得配套 CAST 模型。
- 关闭开关仅停止额外模型文件生成，不删除已有文件，也不移除完整场景 CAST/FBX 本身包含的模型。
- 导出结果显示所有生成文件；模型文件参与源素材覆盖保护和批量输出路径冲突检查。预览不会生成配套模型文件。

## 面板与 Blender 适配

- 双持列表与预览之间、预览与属性栏之间增加可拖动分隔条，支持方向键调整和悬停/焦点提示。
- 双持面板接入「恢复布局」和窗口缩小时的宽度限制，保留预览区空间。
- 随包提供 Blender CAST 插件及后台 FBX 转换脚本，优先检测 Blender 4.3，保留 Maya 转换通道。
- 修复完整 CAST 场景导入 Blender 时，动画没有绑定到新导入骨架的问题；调整骨骼显示长度以降低大坐标下的方向精度损失。

## 使用方法

1. 完整解压压缩包，启动 `AlchemyStars.Avalonia.exe`。请保留同目录的 DLL、`Converters`、`BlenderPlugin` 和 `MayaPlugin`。
2. 在模型部件中选择手臂和一个武器模型，在动画栏目中导入并处理左右动作。
3. 在双持栏目配对来源、设置输出目录，生成预览后导出。按需开启「导出武器模型」。
4. 在 Blender/Maya 中分开使用模型和动画时，先导入 `_model.cast`，选中骨架，再导入「仅动画 CAST」输出。已烘焙动画导入时关闭额外 IK/约束求解。

详细使用说明见压缩包 `Docs/DUAL-WIELD.zh-CN.md`。示例工程仅为配置模板；原始游戏模型、动画和贴图不包含在下载包中。

## 当前限制

- 尚不支持「左、右各一份独立武器模型」或「单文件已包含两把武器」的双持输入。当前仍是一份单持武器模型复制为左右两侧。
- 左右任务及叠加层需使用一致帧率，处理后的总帧数也需一致；不自动重采样或补齐短侧。
- 要求单位绑定缩放，不支持缩放动画；双持需关闭旧版 COD 坐标兼容，并始终采用全骨骼烘焙。
- 没有匹配模型骨骼的源曲线会提示并忽略；缺失贴图不会自动补齐。
- Blender FBX 已接通转换，但严格姿态回读仍存在误差：fire 样例武器根最大位置差约 0.0081 个源单位，远处辅助骨骼最大约 0.4581 个源单位。当前推荐 CAST / `.blend` 作为编辑基线。
- Maya 通道保留，但本次没有 Maya 实机验收；依赖本机缺失的旧 Hawk/MP5 等原始素材的整套回归未全部执行。
