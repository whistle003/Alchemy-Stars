# Alchemy Stars 1.3.0-preview.14 UI.1

此版本保存 `codex/avalonia-ui` 分支上的界面更新，应用内部版本号仍为 `1.3.0-preview.14`。

- Apple 与拟物化两种界面风格，支持浅色、深色和跟随系统；设置即时生效并自动保存。
- 统一蓝白功能图标与操作图标，修正顶部工具提示的文字对比度。
- 双持页面统一任务栏、预览标题栏和属性分组，修正模型导出开关对齐。
- 常规控件保持 44px 高度，保留原有动画处理与导出流程。

Windows x64 下载包为 Native AOT 独立程序，解压后运行 `AlchemyStars.Avalonia.exe`，无需另外安装 .NET。包内保留 Blender/Maya 插件、转换脚本、示例和用户文档。

源码根目录为 `fork/AlchemyStars`，界面项目为 `src/AlchemyStars.Avalonia`。构建使用仓库 `global.json` 指定的 .NET SDK，以及现有 Native AOT 构建环境。

发布前检查包括 Native AOT 编译、应用自检、启动检查、真实外观切换及双持页面渲染。压缩包中的 `BUILD-INFO.json` 记录对应提交与发布标签。
