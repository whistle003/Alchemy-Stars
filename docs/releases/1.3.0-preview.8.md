# Alchemy Stars 1.3.0-preview.8

This is an experimental Windows x64 preview of the Avalonia + Native AOT migration. It does not replace the stable WPF 1.1.9 release.

## Highlights

- Rebuilt the workspace as a compact creative editor with an asset library, real composition preview, ordered animation layers and collapsible inspector.
- Displays the actual merged CAST as clay-shaded geometry with animation playback, frame scrubbing, orbit/zoom, subject/all-geometry framing and optional skeleton overlay.
- Uses distinct, padded toolbar vectors with 44×44 command targets, keyboard focus and screen-reader names.
- Keeps animation, animation-layer, model-part and CAST framing context menus synchronized with the global Chinese/English language selection—never both languages in one command.
- Retains Alchemist/RedFox conversion behavior while adding safer output protection, editable and droppable paths, file-browser history, full/animation-only CAST, SMD, SEAnim, Maya-backed FBX and relevant-bone baking.

## Requirements and preview notes

- Windows x64. The ZIP is self-contained Native AOT and does not require a separate .NET runtime.
- Maya is not bundled. Local Maya 2025 remains required only when exporting FBX and is recommended for final CAST validation.
- Animation-only CAST stores curves without an embedded skeleton. Import or preview it with the matching model skeleton and bind pose.
- This build targets .NET 11 Preview 7 and Avalonia 12.1.2. Keep using stable 1.1.9 for production work until the .NET 11 GA migration is approved.
