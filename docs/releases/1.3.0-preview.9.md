# Alchemy Stars 1.3.0-preview.9

Preview 9 makes the lower animation-layer workspace a duration-aware composition view and changes the default skinning method of merged skinned assets to DQS.

## Changes

- Track bars scale to the real frame count stored in each source CAST and move horizontally with positive or negative layer offsets.
- Persistent frame-count labels, localized tooltips and screen-reader names provide an accessible non-visual description; unreadable sources are marked explicitly.
- The standard Hawk project displays a 1-frame base, a 67-frame sprint-loop layer and a 1-frame additive-offset layer over frames 0–66.
- Merged CAST meshes with bone weights explicitly use `quaternion` skinning. The included Maya importer also defaults unlabelled legacy meshes to DQS while honoring an explicit source method.
- Timing metadata is read asynchronously and never modifies source files.

## Status

This remains a .NET 11 Preview / Avalonia Native AOT test release. WPF v1.1.9 on `main` remains the stable production line until .NET 11 GA.
