# Alchemy Stars 1.3.0-preview.10

Preview 10 improves the CAST viewport's rendering quality, GPU presentation and editor-style playback controls.

## Changes

- Skinned vertex normals replace flat per-face lighting, with a balanced clay material, dual-light shading, controlled highlights and a subtle rim light.
- Legacy CAST meshes without valid normals receive deterministic area-weighted smooth normals.
- Interactive CAST frames are now submitted through Avalonia's Skia custom-draw path, allowing the desktop compositor to rasterize the shaded triangle mesh on the GPU. The deterministic CPU renderer remains only for headless regression and software fallback checks.
- Two-sample multisample anti-aliasing softens silhouettes in the deterministic CPU fallback, while Skia anti-aliasing smooths the interactive GPU preview.
- The Premiere-inspired playback area uses a slim, adaptive frame ruler above a compact transport row. Tick density follows animation length; previous frame, play/pause and next frame stay centered while the current/total frame readout stays at the right edge.
- Preview commands use a tighter 40-DIP footprint with 17-DIP rounded glyphs; status overlays and the first-person badge are more compact.
- The UI font stack is shared by the workspace, menus and tooltips for consistent English and Chinese typography.
- A new sunrise-gold star, sky-blue alchemy flask and animation orbit create a brighter, more legible Avalonia app icon. The transparent PNG and multi-resolution ICO are optimized for both small command surfaces and the About page.
- Preview 9's Maya-compatible first-person camera remains available at `T(0,0,0)`, `R(90°,0°,-90°)`, 90° horizontal FOV. A preview-only whole-scene fit now keeps weapons that cross the camera origin fully inside the viewport without modifying CAST transforms or exported data.

## Status

This remains a .NET 11 Preview / Avalonia Native AOT test release. WPF v1.1.9 on `main` remains the stable production line until .NET 11 GA.
